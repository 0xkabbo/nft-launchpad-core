# NFT Launchpad Core

A professional-grade backend for an NFT Drop. Built with Solidity and Hardhat, flattened for easy management.

## Key Features
- **ERC-721 Standard:** Compatible with OpenSea, Rarible, etc.
- **Supply Management:** Hardcapped maximum supply.
- **Minting Logic:** Cost per mint and max-per-wallet restrictions.
- **Owner Controls:** Withdraw funds and update Base URI for metadata reveals.
